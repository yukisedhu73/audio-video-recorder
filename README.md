# Tech Stack
React + TypeScript

Vite (super fast dev server)

TailwindCSS for styling

Lucide-react for icons

React Router DOM for routing

HTML5 Media APIs

# Clone your repo
git clone https://github.com/yukisedhu73/audio-video-recorder.git
cd audio-video-recorder-app

# Install dependencies
npm install
# or
yarn install

# Start the development server
npm run dev


# Bonus Features Implemented

 Toggle between Audio-only and Video recording modes
 Live Timer showing recording duration
 Permission Handling: Gracefully handles mic/camera permission errors 
 Recordings Library: Displays past recordings (stored in React state , not in local storage)
 Upload to Firebase/S3: Not implemented yet
